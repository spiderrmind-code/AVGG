# Operación de soporte

Los canales y horarios se publicarán cuando estén definidos; no se deben inventar datos de contacto. Como referencia interna, se sugiere registrar cada caso, acusar recibo dentro del SLA operativo definido por la empresa y escalar incidentes de pago, envío o fraude al responsable correspondiente.

Para pagos, conservar el identificador de orden y derivar al flujo de verificación. Para envíos y tracking, consultar el estado operativo sin prometer plazos. Para devoluciones, aplicar la política aprobada. Los posibles fraudes se escalan sin exponer datos de pago. Los incidentes críticos siguen los runbooks de pagos y de incidentes.
