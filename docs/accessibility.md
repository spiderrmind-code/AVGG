# Accesibilidad

El documento usa `lang="es"`, un enlace de salto hacia `#main-content` y un contenido principal identificable. La interfaz conserva nombres accesibles para búsqueda y controles de icono, texto alternativo en imágenes principales y una preferencia global de movimiento reducido.

Las tablas administrativas mantienen encabezados semánticos; la navegación debe poder realizarse con teclado y conservar foco visible. `npm run verify:accessibility` controla estos contratos básicos.

Esto no constituye una certificación WCAG. Se requiere revisión manual con teclado, lector de pantalla y contraste sobre el dominio final.
